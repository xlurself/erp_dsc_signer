# Changelog

## 0.1.0 - 2026-08-10

- Add selectable server-side PFX and workstation USB DSC signing modes.
- Add provider discovery for ePass, SafeNet, ProxKey, WatchData, and generic PKCS#11 middleware.
- Add short-lived, one-use USB signing sessions with server-side PDF and CMS verification.
- Add a loopback-only local signer for Windows and macOS with local PIN prompting.
- Preserve private attachments, historical signed PDFs, timestamps, and `no_copy` Sales Invoice fields.
