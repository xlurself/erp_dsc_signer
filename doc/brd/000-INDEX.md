## How this drives review
When Documentation is enabled and a founder approves the BRD, the approved acceptance criteria and
`doneWhen` are injected into every reviewer prompt as the definition of done. **These markdown files are
the source** — `POST /api/brd/approve` generates `brd.json` from them, so there is nothing to keep in sync.
